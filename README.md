# Enterprise Authentication & User Management System

A production-ready Enterprise Authentication System built with the MERN Stack following industry best practices.

## Features
- JWT Authentication
- Refresh Token Authentication
- Role-Based Access Control (RBAC)
- Secure HTTP-only Cookies
- Email Verification
- Forgot Password
- Reset Password
- User Profile Management
- Admin Dashboard
- User Management
- Activity Logs
- RESTful APIs
- API Validation
- Rate Limiting
- Security Headers (Helmet)
- Docker Support
- CI/CD Pipeline
- AWS Deployment
